# Vyash Skills And Stories

Personal developer portfolio for **S. Vyash** — a single-page site with Home, About, Skills, Projects, Experience, Certifications/Achievements and Contact sections, scroll-reveal animations and active-section navigation.

## Tech stack

- **Framework:** TanStack Start (React 19 + TanStack Router, file-based routing, SSR)
- **Language:** TypeScript
- **Build tool:** Vite 8 (+ Nitro for the server build)
- **Styling:** Tailwind CSS v4, `tw-animate-css`, shadcn/ui components (Radix UI)
- **Icons / fonts:** lucide-react, Devicon (CDN), Google Fonts (Space Grotesk, Manrope, JetBrains Mono)
- **Testing / linting:** Vitest + Testing Library, ESLint, Prettier

## Prerequisites

- **Node.js 20+** (22 recommended) and npm — or [Bun](https://bun.sh)
- An internet connection when viewing the site (fonts and technology logos load from CDNs)

## Install

```sh
npm install --legacy-peer-deps
```

> `--legacy-peer-deps` is recommended: a plain `npm install` can fail with an npm internal error (`Cannot read properties of null (reading 'edgesOut')`) on this dependency tree.
> If you use Bun, `bun install` works with the included `bun.lock`.

## Run

```sh
npm run dev        # dev server with hot reload (default http://localhost:5173)
npm run build      # production build -> .output/
npm run preview    # preview the production build
npm run test       # run tests
npm run lint       # lint
```

```
├── package.json, bun.lock, tsconfig.json, eslint.config.js, ...
```

## Editing content

Almost all text, links, skills, projects and certificates live in `src/data/portfolio.ts`.
To enable the resume download button, put your PDF in `public/` and set `resumeUrl: "/resume.pdf"` in that file (it is currently empty, so the button is hidden).
